# Hospital-Management-System


## Project Overview
The Hospital Management System is a database project developed using MySQL. It stores and retrieves information about patients, doctors, appointments, rooms, admissions, and bills.

The project demonstrates SQL concepts including table creation, primary and foreign keys, data insertion, filtering, joins, aggregate functions, subqueries, updates, deletes, views, stored procedures, and reports.

## Technologies Used
- MySQL
- SQL

## Database
Database name: `hospitaldb`

## Tables
1. `Patients` – patient details and registration information.
2. `Doctors` – doctor details and specializations.
3. `Rooms` – room types and availability.
4. `Appointments` – appointments connecting patients and doctors.
5. `Admissions` – patient admissions and assigned rooms.
6. `Bills` – patient billing and payment status.

## Main Features
- Store patient and doctor information.
- Manage appointments and admissions.
- Track room availability.
- Maintain patient bills and payment status.
- Retrieve information using SQL joins and subqueries.
- Generate summary reports using aggregate functions.
- Create reusable views and stored procedures.

## How to Run
1. Install and open MySQL Command Line or MySQL Workbench.
2. Open `hospital_management.sql`.
3. Run the script in a fresh MySQL environment. It creates the `hospitaldb` database and its six tables.
4. Check the tables using:
   ```sql
   USE hospitaldb;
   SHOW TABLES;
   ```
5. Run individual SELECT statements or procedure calls to explore the results.

**Important:** Run the SQL script once in a fresh database. Running it again without resetting the database will cause duplicate table, view, procedure, or primary-key errors. The UPDATE and DELETE section intentionally changes the sample records.

## Stored Procedures
- `InsertPatient` – inserts a patient using input parameters.
- `UpdateRoomStatus` – updates a room's availability.
- `GetPatientAppointments` – displays appointments for a selected patient.
- `CalculateTotalRevenue` – calculates total billed amount.
- `GetDoctorsBySpecialization` – lists doctors by specialization.

## Reports
The project includes reports for:
- Top doctors by appointment count.
- Most frequent patients.
- Monthly appointment totals.
- Patient billing analysis.
- Most demanded specialization.
- Doctor-associated billing estimate.

## Data Model Limitation
The assignment's `Bills` table contains `patient_id` but does not contain `doctor_id` or `appointment_id`. Therefore, the doctor revenue report associates a patient's bill with doctors that the patient visited. If a patient visited multiple doctors, the same bill may be counted for more than one doctor. This is an estimate, not a reliable measure of revenue generated by each doctor. For accurate doctor-wise revenue, the database should link each bill to the relevant doctor or appointment.
